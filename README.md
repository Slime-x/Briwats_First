# HookUP

A game made in Godot about a guy who uses a gun to hook to walls there is around ~10 levels, the player can only move using his hooking/grapple gun, which is the principle of the game, also there is a storyline :eyes:
	
We didn't follow harvest theme :(
## How to play?

You can hook to walls by clicking on them using your mouse.
Pulled the rope by pressing 'R'. It should be easier to play using R a lot
Press 'A' and 'D' to move left and right while hooking
Press [ESC] to change unlocked level. 
Press W A S D and [Jump] to move normally.
