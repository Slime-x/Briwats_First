# HookUP

A game made in Godot about a guy who uses a gun to hook to walls there is around ~10 levels, the player can only move using his hooking/grapple gun, which is the principle of the game, also there is a storyline :eyes:
	
We didn't follow harvest theme :(
## How to play?

You can hook to walls by clicking on them using your mouse And you can get pulled towards them by pressing 'R' Also you can press 'A' and 'D' to move left and right while hooking
